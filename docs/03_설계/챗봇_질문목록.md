- 이 문서에는 **질문과 처리 방식만** 적는다. 답 문장은 아직 없다.
- 답 문장은 AI가 만들지 않는다(`report/설계/챗봇_설계_초안.md` 2-2). 팀이 미리 써서 검토한 고정 문장으로 답하고, 문장마다 출처(법령·국세청·한국거래소 등)를 단다.

## 처리 방식

| 표시 | 뜻 |
|---|---|
| 설명 | 팀이 써 둔 쉬운 설명 문장으로 답한다 |
| 설명 + 점검 | 설명한 뒤 [보유 종목 입력] 칩으로 점검을 이어 준다 (이 서비스의 핵심 주제) |
| 고정 안내 | 판단·추천·예측을 묻는 말. 가드레일 고정 문구로 답한다 (설계 초안 2-3) |
| 설명 + 고정 안내 | 개념 부분은 설명하고, "그래서 사도/팔아도 되나" 같은 판단 부분은 고정 안내로 돌린다 |
| 서비스 소개 | 이 챗봇이 하는 일을 소개하는 고정 문장 |

"가드레일 지금"은 `source/core/chat_guard.check()`에 질문 문장을 그대로 넣어 본 결과다(2026-10-29 단어 목록 고친 뒤, 아래 '가드레일 점검' 참고). `-`는 걸리지 않음.

## 가드레일 점검 (2026-10-29)

질문 66개 중 같은 문장 1개를 뺀 65개를 `source/core/chat_guard.check()`에 그대로 넣어 봤다.

**처음 결과 (고치기 전):** 7개가 걸렸고, 아래가 문제였다.
- 잘못 걸림: 4-4 "배당락일에는 **주가**가 왜 떨어져?", 5-7 "**주가**가 오르면 배당금도 늘어나?". 개념 질문인데 '주가'라는 단어만 보고 막았다.
- 이유가 틀림: 9-2·9-3 "좋은 **회사야**?", "나쁜 **회사야**?". '회사야' 안의 '사야'에 걸렸다.
- 못 걸림: 9-4 "다음 배당을 **예측**할 수 있어?", 4-7 "받자마자 **팔아도 돼**?".

**고친 것 (`source/core/chat_guard.py`의 종목·주가 단어):**
- 뺌: '주가', '사야'
- 넣음: '사야 할까'·'사야 해'·'사야 돼'·'사야 하나', '사도 돼'·'사도 되', '팔아도 돼'·'팔아도 되', '주가 어때', '예측', '좋은 회사'·'나쁜 회사'

**고친 뒤 결과:** 6개가 걸린다. 9-1~9-4, 4-7, 10-2이다. 4-4·5-7은 통과한다.
- 10-2 "고배당 주식을 **추천**하면 뭐가 좋아?"는 계속 막힌다. 서비스 소개로 답할 자리가 생기면 다시 본다.
- 위 문장들은 `source/tests/test_chat_guard.py`에 '걸려야 하는 문장'과 '걸리면 안 되는 문장'(`test_concept_questions_are_not_blocked`)으로 넣었다.
