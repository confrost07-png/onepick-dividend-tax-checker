# 프런트엔드 설계: Streamlit 밖으로 (v0.3, 모아 디자인)

- 작성: 2026-10-28
- 상태: **설계안과 화면 시안**이에요. 앱 코드는 바꾸지 않았어요.
- 2026-10-29 갱신: v0.4 디자인(`archive/design_drafts/원픽_프런트_디자인_20261029.html`, 법 토너먼트·데이터 이야기 5장)으로 실제 화면을 만들었어요. 코드는 `source/api/`(FastAPI)와 `app/web/`(React), 실행 방법은 README '새 화면'. 5절 API 표에 `/api/judgement/funnel`, `/api/analysis`, `/api/chat/script`, `/api/law/evidence`가 더해졌어요.
- 시안: `archive/design_drafts/원픽_모아_시안_20261028.html`
  - 브라우저로 열면 네 화면을 오가며 눌러 볼 수 있어요.
  - 그림이 파일 안에 들어 있어서 이 파일 하나만 보내도 돼요.
- 바뀐 과정
  - v0.1: 지금 앱의 디자인(픽이)을 그대로 옮김 → 새 디자인이 아니라서 버림.
  - v0.2: 통장과 도장, 마스코트 꾹이 → 마스코트 모양이 이상하고 화면이 낡아 보인다는 지적을 받아 버림.
  - v0.3: 요청하신 "카카오뱅크처럼 귀엽게"에 맞춰 새로 만듦.
- 그대로 지키는 원칙
  - 세법 해석을 AI가 만들지 않아요.
  - 조문은 원문 그대로 검색만 해요.
  - 고객 입력값을 저장하지 않아요.
  - 종목 추천처럼 보이는 표현을 쓰지 않아요.
  - 분석 화면에 회사 이름이나 순위를 보여 주지 않아요.

## 1. Streamlit 때문에 못 했던 것

| Streamlit의 한계 | 지금 앱에서 보이는 모습 | 새 프런트엔드에서 |
|---|---|---|
| 버튼 하나에 화면 전체가 다시 그려짐 | 챗봇에서 답할 때마다 깜빡이고 스크롤이 튐 | 바뀐 부분만 다시 그림. 대화는 아래에 붙고, 오른쪽 '내 답'에 한 칸만 새로 채워짐 |
| 자바스크립트가 돌지 않음(`st.html`) | 움직임은 CSS로만, 그래프 위에 마우스를 올려도 설명이 안 뜸 | 모아 등장과 금화 게이지 움직임, 막대마다 마우스와 키보드로 설명 |
| 화면을 나란히 고정할 수 없음 | 결과가 대화 아래로 길게 이어짐 | 왼쪽은 대화, 오른쪽은 '내 답'(스크롤해도 고정) |
| 옆에서 열리는 창이 없음(`st.dialog`는 가운데 팝업) | [근거 보기]가 대화 속 긴 글로 들어감 | 오른쪽 서랍으로 조문 원문을 열고, 대화는 그대로 둠 |
| 주소 체계가 `?code=`뿐 | 회사 상세만 주소로 공유 | `/company/005930`, `/analysis`, `/check` 같은 진짜 주소. 뒤로 가기도 그대로 동작 |
| 입력 상자 꾸미기에 한계 | 회사 고르기가 기본 선택 상자 | 글자를 치는 동안 후보가 뜨는 검색(↑↓·Enter·Esc). 어디서든 `/` 키로 열기 |

## 2. 디자인 방향: 귀엽고 쉬운 모바일 은행 화면

- **참고한 느낌**: 카카오뱅크처럼 귀엽고 쉬운 화면이에요. 흰 바탕에 크고 둥근 카드를 쓰고, 캐릭터가 중심에 서요. 숫자는 큰 글씨로 하나만 보여 주고, 말투는 다정하게 해요.
- **베끼지 않은 것**: 카카오뱅크의 노랑·검정 브랜드 색, 카카오프렌즈 캐릭터, 카카오톡 말풍선 색은 쓰지 않았어요. Codex에게도 기존 캐릭터와 닮지 않게 하라고 지시했어요.
- **기억에 남길 한 곳**: 회사를 고르면 모아가 판정에 맞는 표정으로 튀어나와요. 금화 게이지는 2025년 배당만큼 차오르고, 2027년 최소 필요선과 비교돼요.

### 2-3. 마스코트 '모아'

- 모습: 동그란 아기 수달이 배 위에 금화를 꼭 안고 있어요. 수달이 좋아하는 돌을 품에 모아 두는 습성을 배당을 모아 두는 것에 빗댔어요.
- 표정 네 가지

| 그림 | 쓰는 곳 |
|---|---|
| 기본(금화 안고 미소) | 첫 화면 대기, 대화 얼굴, 점검 시작하기 카드 |
| 기뻐함(금화 번쩍) | 요건 넘음, 그래프 25% 막대 위 |
| 시무룩(눈물 한 방울) | 요건 못 넘음 |
| 갸우뚱 | 판단 보류, 분석 보기 카드 |

- 만든 방법
  - Orca로 Codex 작업 공간(`onepick-mascot-moa`)을 만들었어요(2026-10-28).
  - Codex 기본 이미지 생성 기능만 쓰게 했어요. 셸 명령, 파일 수정, 유료 API는 쓰지 않게 했어요.
  - 기본 그림을 먼저 그린 뒤, 그 그림을 기준으로 나머지 세 표정을 그렸어요.
  - 원본은 1254px 투명 PNG예요. 화면용으로 512px webp로 줄였어요.
- 파일: `archive/design_drafts/모아_시안_원본/moa/moa_{base,happy,sad,curious}.webp`

## 4. 화면별 설계

### 4-1. 첫 화면 `/`

- 파란 큰 카드: 제목 "내 배당, 내년에도 분리과세 될까요?", 회사 검색, 예시 칩, 모아를 둬요.
- 회사를 고르면 화면을 옮기지 않고 아래에 답 카드가 나와요. 답 카드에는 다음이 들어가요.
  - 모아 말풍선과 판정 배지
  - 큰 한 줄: "2027년엔 2025년보다 11,107.9억 원 더 줘야 해요" 또는 "2025년만큼만 줘도 2027년 요건을 넘어요"
  - 금화 게이지
  - 숫자 세 칸
- 아래에는 "638곳 중 530곳이 올해 요건을 넘었어요"와 세 칸 막대를 둬요.
- 맨 아래에는 점검 카드와 분석 카드를 둬요.

### 4-2. 점검 `/check` (챗봇 add-on)

- 맨 위 진행 막대 여섯 칸: 끝난 칸은 파랑, 지금 칸은 노랑이에요. 'n/6' 숫자는 쓰지 않아요.
- 왼쪽은 대화예요. 모아 말풍선은 회색, 내 답은 파랑이에요. 칩은 연파랑이에요.
- 오른쪽은 '내 답' 카드 다섯 칸이에요.
  - 답하면 칸이 톡 튀며 값이 들어가요.
  - 답한 칸을 누르면 그 항목만 다시 물어요.
- 결과 카드는 이 순서예요.
  1. 한 줄 요약(지금 `_headline` 문장 그대로)
  2. 세금 차이 큰 숫자(6,227,720원 (감소))
  3. 신청 전과 신청 후 두 줄
  4. 종목별 모아 표정과 판정 배지
  5. 내년 조건
  6. 가정 문구
- [근거 보기]를 누르면 오른쪽(휴대폰은 아래)에서 조문 원문 시트가 열려요. 시트 맨 위에 "원문 그대로예요. AI가 쓴 문장이 아니에요."를 둬요.

### 4-3. 회사 보기 `/company/:code`

- 첫 화면과 같은 답 카드를 쓰고, 그 아래에 공시 원문 링크를 둥근 칩으로 둬요.
- '주소 복사' 버튼이 있어요. 회사별 공시 뒤 주가 반응은 보여 주지 않아요(팀 원칙).

### 4-4. 데이터 분석 `/analysis`

- 연회색 큰 카드 두 장을 둬요.
- 첫 카드는 기준선 계단 그래프예요.
  - 막대는 둥근 모서리이고, 25% 미만은 회색, 25% 이상은 파랑이에요.
  - 기준선에는 검은 이름표("25% 기준선", "40% 기준선")를 붙여요.
  - 마우스를 올리거나 Tab으로 고르면 "25%대 65곳"이 뜨고, 고른 막대는 노랑으로 바뀌어요.
  - 25% 막대 위에 기뻐하는 모아가 있어요.
- 둘째 카드는 다음 해 탈락률이에요. 둥근 가로 막대이고, 2024년은 노랑이에요.


## 5. 구조 (제안)

```
브라우저 (React + TypeScript, Vite)
   │  JSON
   ▼
FastAPI (Python)  ── 지금 source/core/ 모듈을 그대로 가져다 씀 (계산 로직 다시 쓰지 않음)
   │
   ▼
PostgreSQL onepick  /  Ollama (qwen3.5:4b 값 뽑기, bge-m3 조문 검색)
```

| API | 하는 일 | 쓰는 지금 코드 |
|---|---|---|
| `GET /api/companies?q=` | 회사 이름 후보 | `chatbot._real_companies()` → `core.company_repo`로 옮김 |
| `GET /api/companies/{code}` | 판정, 2027 최소 필요, 재무 여력, 원문 링크 | `core.checkup.check_stock`, `company_repo` |
| `GET /api/judgement/counts` | 판정 세 칸 막대 | `company_repo.judgement_counts` |
| `POST /api/chat/parse` | 고객 문장에서 값만 뽑기 | `core.chat_parse`, `core.chat_guard` |
| `POST /api/checkup` | 세액 비교 결과 | `core.checkup.run_checkup` |
| `GET /api/law/search?q=` | 조문 원문 문단(검색만) | `core.law_search` |
| `GET /api/analysis/threshold` | 기준선 계단 그래프 데이터 | `core.p1_analysis.load` |

- **고객 입력값은 저장하지 않음**
  - 점검 상태는 브라우저 메모리에만 둠.
  - `/api/checkup`은 요청 본문을 기록하지 않음(접속 기록에서 본문 제외).
- **그래프**
  - SVG를 직접 그림.
  - 금화 게이지, 세 칸 막대, 기준선 계단은 이 서비스만의 그림이라 차트 라이브러리 기본 모양을 쓰지 않음.
- **테스트**
  - 지금 pytest 333개는 core에 걸려 있어 그대로 씀.
  - 화면 테스트는 Playwright로 새로 씀(지금의 AppTest 대신).

## 6. 일정 판단 (중요)

- 제출이 **11/04 10:00**이고 10/29~11/01은 2-1 필수 일정이에요.
