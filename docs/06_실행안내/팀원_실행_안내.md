# 원픽 팀원 실행 안내

받은 압축 파일 하나로 원픽 웹 화면(홈·내 배당 점검·데이터 이야기·금융 상식·자산관리)을 내 컴퓨터에서 띄우는 방법입니다.
처음 한 번만 1~3을 하고, 다음부터는 4만 하면 됩니다.

## 압축 파일에 든 것

| 들어 있는 것 | 설명 |
|---|---|
| 코드 (`source/api/`, `source/core/`, `app/web/` 등) | 커밋된 코드 전체. 비밀 파일(`.env`)과 `node_modules`는 넣지 않았어요 |
| `app/web/dist/` | 미리 만들어 둔 화면. Node.js가 없어도 됩니다 |
| `data/db/onepick_날짜.dump` | 분석 DB `onepick` 전체 덤프 (PostgreSQL 17, 638사 확정판) |
| `data/db/onepick_날짜.json` | 덤프 확인표. 파일 SHA-256과 뽑을 때의 표별 행 수·판정 집계가 들어 있어요. 덤프와 꼭 함께 두세요 |
| `requirements.txt` | 파이썬 패키지 목록(버전 고정) |
| `source/scripts/restore_db.py` | 덤프를 내 PostgreSQL에 복원하고, 확인표와 행 수를 대조하는 스크립트 |

## 1. 준비물 설치

- **Python 3.11 이상**. 맥에 원래 있는 `python3`는 3.9라서 안 돼요. 아래 2의 uv 방법을 쓰면 알맞은 파이썬을 알아서 받아 줘요.
  - uv 설치(맥): 터미널에 `curl -LsSf https://astral.sh/uv/install.sh | sh`
  - uv 설치(윈도우 PowerShell): `powershell -c "irm https://astral.sh/uv/install.ps1 | iex"`
- **PostgreSQL 17 이상** (덤프를 17에서 만들어서 16 이하로는 복원이 안 돼요)
  - 맥: [Postgres.app](https://postgresapp.com) 설치 → 앱을 열고 Initialize. 접속 주소는 기본값 그대로 씁니다.
  - 윈도우: [PostgreSQL 공식 설치본](https://www.postgresql.org/download/windows/) 17 설치. 설치할 때 정한 `postgres` 비밀번호를 기억해 두세요.
- Ollama는 없어도 됩니다. 없으면 문장 해석·금융 상식 찾기를 규칙·글자 검색으로 대신해요.

## 2. 파이썬 패키지 설치 (압축을 푼 `onepick` 폴더에서)

uv로 하기(추천, 맥·윈도우 같음):

```bash
uv venv --python 3.12 .venv
```

```bash
uv pip install --python .venv -r requirements.txt
```

uv 없이 하기: Python 3.11 이상을 [python.org](https://www.python.org/downloads/)에서 설치한 뒤

```bash
python3.12 -m venv .venv
```

```bash
.venv/bin/pip install -r requirements.txt
```

윈도우는 `py -3.12 -m venv .venv` 다음 `.venv\Scripts\pip install -r requirements.txt`.

## 3. DB 복원

DB 연결 주소는 환경변수 `DATABASE_URL`로 정합니다(`source/core/db.py`). 정하지 않으면 `postgresql://localhost/onepick`을 씁니다.

맥(Postgres.app 기본값이면 주소를 정할 필요 없음):

```bash
.venv/bin/python -m scripts.restore_db
```

윈도우(비밀번호 자리에 설치할 때 정한 값을 넣기):

```bat
set DATABASE_URL=postgresql://postgres:비밀번호@localhost:5432/onepick
.venv\Scripts\python -m scripts.restore_db
```

`source/db/` 안의 가장 최근 덤프를 골라, 확인표와 파일이 같은지 먼저 본 뒤 복원합니다. 복원이 끝나면 표마다 행 수와 판정 집계를 뽑을 때와 대조해요.
마지막에 `되살리기 완료 … 판정 회사 638곳`과 `모두 뽑을 때와 같아요`가 나오면 정상입니다.
이미 복원한 DB를 새 덤프로 바꿀 때는 `--replace`를 붙입니다. 이때 그 DB를 통째로 지우고 다시 만들어요(서버를 켜 둔 창이 있으면 연결이 끊겨요).

## 4. 실행

맥:

```bash
.venv/bin/python -m scripts.run_api
```

윈도우(3에서 `DATABASE_URL`을 정한 같은 창에서):

```bat
.venv\Scripts\python -m scripts.run_api
```

브라우저에서 http://127.0.0.1:8000 을 엽니다. 끌 때는 그 창에서 Ctrl+C.

- 포트를 바꾸려면 `--port 8010`처럼 붙입니다.
- 창을 새로 열면 윈도우는 `set DATABASE_URL=...`을 다시 해야 합니다.

### Streamlit으로 같은 화면 보기 (선택)

웹(8000)과 같은 화면·문구·숫자를 Streamlit으로 본뜬 앱이 `app/`에 있습니다. 숫자는 웹이 부르는 `source/api/main.py` 함수를 그대로 불러 쓰므로 8000 서버를 따로 켜지 않아도 됩니다(DB는 3에서 복원한 `onepick`). 처음 한 번 `.venv/bin/pip install "streamlit>=1.50"`(윈도우 `.venv\Scripts\pip ...`)로 설치하고, 저장소 맨 위 폴더에서 `.venv/bin/streamlit run app/app.py`를 실행해 http://localhost:8501 을 엽니다. 웹의 문구(약관·칼럼·은행 모형 자료)와 법 토너먼트 그림은 `app/web_text.json`·`web_tournament.js`로 뽑아 두었고, 웹 글이 바뀌면 `node app/export_web_text.mjs`로 다시 뽑습니다. 웹과 다른 점과 숫자 대조 결과는 `report/검증/Streamlit_웹_대조_결과.md`에 있습니다.

## 5. 데이터를 DuckDB 파일 하나로 내보내기 (팀 공유용)

DB(`onepick`)의 원천(`raw`)·세율표(`ref`)·검증·확정(`core`)·대조군(`partner`) 표와 보기(`v_*_verified`, `partner.v_panel` 등)를 `.duckdb` 파일 하나에 담습니다. 보기는 지금 값 그대로 표로 굳혀 넣어요.

처음 한 번:

```bash
.venv/bin/python -m pip install duckdb
```

내보내기(DB가 켜져 있어야 해요. 윈도우는 `.venv\Scripts\python`, 3에서 정한 `DATABASE_URL`과 같은 창에서):

```bash
.venv/bin/python -m scripts.export_duckdb
```

`data/db/onepick_오늘날짜.duckdb`가 생깁니다. 표마다 PostgreSQL과 행 수가 같은지 확인하고, 다르면 멈춥니다.
어느 표를 언제 옮겼는지는 파일 안 `main._about` 표에 있어요. 시간대 있는 시각은 UTC로, 배열·JSON은 JSON 글자로 옮겨요.

## 막힐 때

| 증상 | 할 일 |
|---|---|
| `No module named 'fastapi'` | 파이썬이 3.11보다 낮아 설치가 안 된 거예요. `.venv`를 지우고 2를 uv 방법으로 다시 |
| `No module named 'scripts'` (또는 `'core'`) | 맥이 설치 파일(`.pth`)에 숨김 표시를 붙여 파이썬이 건너뛴 거예요. 명령 앞에 `PYTHONPATH=source `를 붙여 실행해요(예: `PYTHONPATH=source .venv/bin/python -m scripts.run_api`). `chflags nohidden .venv/lib/python*/site-packages/*.pth`로 표시를 떼도 다시 붙을 수 있어요 |
| `pg_restore을 찾지 못했어요` | PostgreSQL 17을 설치했는지 확인. 다른 곳에 깔았다면 그 `bin` 폴더를 PATH에 추가 |
| `unsupported version` (복원 중) | PostgreSQL 16 이하예요. 17 이상으로 설치 |
| `password authentication failed` | `DATABASE_URL`의 비밀번호 확인 |
| 화면에 "숫자를 불러오지 못했어요" | 서버 창에 오류가 있는지, DB 복원이 끝났는지 확인 |
| `DB가 이미 있어요` | 새 덤프로 바꾸려면 `--replace`를 붙여 다시 실행 |
| `확인표가 없어요` | 덤프와 같은 이름의 `.json`을 `source/db/`에 함께 두기 |
| `SHA-256 불일치` | 덤프 파일이 받는 중에 깨졌어요. 다시 받기 |
| `뽑을 때와 다른 곳이 있어요` | 복원은 됐지만 행 수가 달라요. 나온 목록을 그대로 덤프 보낸 사람에게 전달 |

## 알아 둘 점

- A은행·PB센터·세무상담 예약은 모형이라 실제로 신청되지 않고, 입력은 저장하지 않아요.
- 회사 판정·분석 숫자는 DB의 실제 공시 자료(2026-10-29 기준)예요. 칼럼 글과 금융 상식 답은 팀 검토 전 초안이에요.
- 코드를 고쳐 화면(`app/web/src`)을 바꾸려면 Node.js를 깔고 `npm --prefix app/web install`, `npm --prefix app/web run build`를 합니다(README 참고).
