## 3. 공유 링크가 안 열릴 때 (예비 실행)

공유 링크는 **https://onepick-blush.vercel.app** 하나예요(2026-11-03부터 고정 주소). 화면은 Vercel에 있고, 채팅·계산은 이 맥의 API 서버가 Tailscale Funnel(`https://macbookpro.tailf0d8c1.ts.net`)로 받아요. API 서버는 LaunchAgent `com.onepick.api`로 늘 켜져 있고, 꺼져도 몇 초 안에 다시 켜져요. 그래도 **맥이 잠들거나 인터넷이 끊기면** 화면만 열리고 채팅·계산이 안 돼요. 시연 때는 아래 순서로 대비해요.

1. **가장 안전: 발표 노트북에서 바로 켜기** (인터넷 없이도 됨)
   ```bash
   cd ~/Desktop/FINAL_PROJECT_ONE_PICK
   PYTHONPATH=source .venv/bin/python -m scripts.run_api --port 8000
   ```
   (이 맥에서는 LaunchAgent가 이미 8000번으로 켜 두었으니 따로 켜지 않아도 돼요. 위 명령은 다른 노트북에서 켤 때 써요.)
   브라우저에서 http://127.0.0.1:8000 을 열어요. 웹 화면은 `app/web/dist`(빌드해 둔 것)를 그대로 써요. 화면을 고쳤다면 먼저 `cd app/web && npm run build`.
2. **AI가 꺼져 있어도 시연은 돼요**: Ollama가 없으면 입력 해석은 규칙만으로, 금융 상식·조문 찾기는 글자 검색으로 바뀌어요. 사진 읽기만 안 돼요. 시연 전에 `ollama list`로 `qwen3.5:4b`, `bge-m3`가 있는지 확인해요.
3. **Streamlit 예비 화면**: `.venv/bin/streamlit run app/app.py` → http://localhost:8501 (8000 서버 없이도 같은 숫자).
4. **공유 링크가 채팅·계산만 안 될 때**: 이 맥에서 `curl https://onepick-blush.vercel.app/api/health`가 `{"ok":true,"companies":638}`인지 봐요. 아니면 `launchctl list | grep onepick`으로 API 서버가 떠 있는지, `cd source && uv run python -m scripts.serve_public status`로 Funnel이 켜져 있는지 확인하고, 꺼져 있으면 `cd source && uv run python -m scripts.serve_public start`로 다시 켜요(자세한 건 `배포_안내.md`). 주소는 바뀌지 않으니 팀에 새로 알릴 필요는 없어요.
5. **시연 영상**: 위 1장 순서(고형식 → 김춘배 → 세무상담 신청 → 마이페이지)를 그대로 녹화해 두세요. 녹화 전 마이페이지의 지난 신청 내역은 [신청 취소]로 정리해 두면 화면이 깔끔해요. (녹화는 팀이 해야 해요. 이 문서를 쓴 세션은 화면 녹화를 하지 않았어요.)
