# 시연판 배포 안내 (Vercel + 이 Mac)

웹 화면은 Vercel에 올리고, 채팅·계산을 하는 API 서버는 이 Mac에서 돌린다.
Ollama(AI)는 API 서버와 같은 Mac에서 `localhost`로만 불러서, 고객 입력을 바깥 AI 회사로 보내지 않는다.

```
사용자 브라우저 → Vercel (app/web/, 무료 주소 ○○.vercel.app)
                    │ /api 요청만 넘김 (app/web/vercel.json rewrites)
                    ▼
        Tailscale Funnel https://macbookpro.tailf0d8c1.ts.net
                    ▼
        이 Mac: FastAPI(127.0.0.1:8000) → Ollama(localhost:11434) · PostgreSQL(onepick)
```

## 한 번만 하는 준비 (계정이 필요해서 직접 해야 하는 일)

1. **Tailscale Funnel 켜기**: 이 Mac은 이미 Tailscale에 로그인되어 있다(`macbookpro.tailf0d8c1.ts.net`).
   관리 화면(login.tailscale.com/admin)에서 DNS → HTTPS Certificates를 켜고, Funnel을 허용한다.
   처음 `serve_public start`를 실행하면 Tailscale이 허용 링크를 보여 줄 수 있다. 그 링크를 열어 허용하면 된다.
2. **Vercel 가입·로그인**: vercel.com에서 가입한다(Hobby 무료). 이 저장소는 GitHub에 없으므로 명령줄로 올린다.

   ```bash
   cd app/web && npx vercel login
   ```

## 배포 (화면을 바꿀 때마다)

```bash
cd app/web && npx vercel --prod
```

처음 실행하면 프로젝트 이름을 묻는다(예: `onepick`). 프레임워크는 `app/web/vercel.json`에 Vite로 적어 두었다.
끝나면 공개 주소가 나온다. 지금 주소는 `https://onepick-blush.vercel.app`(프로젝트 `onepick`).

## 시연할 때 (이 Mac에서)

```bash
cd source && uv run python -m scripts.serve_public start
```

- DB(회사 638곳)·Ollama 모델(qwen3.5:4b, bge-m3)을 확인하고, API를 켜고, Funnel을 켜고, 잠자기를 막는다.
- 2026-11-03부터 API는 LaunchAgent `~/Library/LaunchAgents/com.onepick.api.plist`로 늘 켜져 있다(맥 로그인 때 시작, 죽으면 다시 켬, 오류 기록 `~/Library/Logs/onepick-api.log`). 그래서 `stop`은 Funnel만 끄고 API는 끄지 못한다. API까지 끄려면 `launchctl bootout gui/$(id -u)/com.onepick.api`.
- 서버 코드(`source/`)를 고친 뒤에는 API를 다시 켜야 반영된다: `launchctl kickstart -k gui/$(id -u)/com.onepick.api`.
- 상태 보기: `cd source && uv run python -m scripts.serve_public status`
- 끄기: `cd source && uv run python -m scripts.serve_public stop`

## 알아 둘 점

- **Mac이 켜져 있어야 한다.** 잠자기는 막지만 덮개를 닫으면 잠들 수 있다. 꺼져 있으면 화면은 열려도 채팅·계산이 안 된다.
- **동시에 여럿이 쓰면 느리다.** Ollama는 요청을 대체로 하나씩 처리한다. 검토·시연 몇 명 정도를 생각한 구성이다.
- **기다리는 시간 한도**: Vercel이 바깥 서버 응답을 기다리는 시간은 120초다(Vercel changelog "CDN origin timeout increased to two minutes"). 사진 읽기가 이보다 오래 걸리면 끊긴다.
- **API 주소도 공개다.** `https://macbookpro.tailf0d8c1.ts.net/api/...`는 Vercel을 거치지 않고도 열린다. 실제 개인정보를 넣지 않는 시연판으로만 쓴다.
- **연결 정보**: 요청은 Vercel·Tailscale을 거친다. 접속 IP·요청 주소(질문 문장이 담길 수 있음)가 그쪽에서 처리·기록될 수 있다. 개인정보 안내(app/web/src/legal.ts 제5조 시연판 안내)에 적어 두었다.
- **초대한 사람만 보게 하기**: Vercel의 Deployment Protection으로 막을 수 있는데, 무료 요금제에서 어디까지 되는지는 아직 확인하지 않았다.
- **Mac 주소가 바뀌면**: `serve_public start`가 `app/web/vercel.json`의 주소와 다르다고 알려 준다. 고친 뒤 다시 배포한다.
