# Streamlit 화면과 웹 화면 대조 결과 (2026-11-02)

Streamlit 앱(`app/`)이 웹(React, `app/web/src`, 8000 서버)과 같은 내용·같은 숫자를 보여 주는지 코드로 견준 결과예요. 기준은 main f691e6f 코드예요.

## 어떻게 만들었나

- **화면과 순서**: `app/web/src/App.tsx` 라우트 그대로 홈 · 내 배당 점검 · 데이터 이야기 · 금융 상식 · 자산관리 · 제도별 비교가 위쪽 메뉴에 있고, 회사 보기(`/company?code=`) · 세무상담 신청 · 내 정보 · 마이페이지 · 개인정보 처리 안내 · 이용약관(특약)은 메뉴에 없는 숨은 화면이에요. 탭 제목도 웹과 같아요('OO · 원픽').
- **숫자**: 웹이 부르는 FastAPI 함수(`source/api/main.py`)를 `app/common.py`의 `api`가 그대로 불러요. 응답은 FastAPI와 같은 JSON 변환을 거쳐 웹이 받는 값과 같은 모양이에요. 계산을 새로 짜지 않았어요. 반올림은 JS(`toFixed`·`toLocaleString('ko-KR')`·`Math.round`)와 같은 규칙으로 맞췄어요.
- **문구**: 화면 글은 각 `pages/*.tsx`에서 그대로 옮겼고, 길고 자주 바뀌는 글(약관·칼럼 45편·용어 사전·은행 모형 자료)은 `node app/export_web_text.mjs`로 웹 TS 파일에서 `web_text.json`으로 뽑아 써요(손으로 옮겨 적지 않음).
- **모양**: 웹의 `app/web/src/index.css`를 그대로 읽어 넣고 웹과 같은 class 이름의 HTML·SVG를 그려요(바다 파랑 #3D6BFF, 동전 노랑 #FFC93C, Do Hyeon·Gothic A1, 모아 그림 `app/web/public/moa`). 데이터 이야기 그림은 `story_charts.py`가 웹 `charts*.tsx`·`control.tsx`·`macro.tsx`와 같은 좌표로 SVG를 만들어요.
- **웹 그림 엔진을 그대로 쓴 곳**: 법 토너먼트(`tournamentEngine.ts` → `web_tournament.js`)와 칼럼의 예시용 그림 도구 39개(`columnToys.tsx` → `web_column_toys.js`, `export_column_assets.mjs`)는 웹 코드를 한 파일로 묶어 Streamlit 안에서 돌려요. 서버 숫자를 쓰는 칼럼 도구 3개(세율 계단 `api.separate`, 달리기 시합 `api.race`, 점 찍어 보기 `api.spread`)는 Streamlit 위젯과 SVG로 새로 그렸어요.
- 회사 이름은 웹과 같은 규칙으로만 보여요(회사 보기·검색·점검 결과에만, 데이터 이야기는 집계만).

## ② 화면 대조: 보이는 글 속 숫자

`app/verify/page_numbers.py` — 같은 화면을 웹(8000)과 Streamlit에서 연 뒤 보이는 글(innerText, `<details>`는 모두 펼침)을 저장하고, 숫자 덩어리만 골라 견줘요. Streamlit 쪽은 위쪽 머리와 아래쪽 안내(공용 틀)를 뺐어요.

| 화면 | 웹 숫자 | Streamlit 숫자 | 겹침 | 웹에만 | Streamlit에만 |
|---|---:|---:|---:|---:|---:|
| analysis | 1418 | 1418 | 1418 | 0 | 0 |
| column-gates | 64 | 64 | 64 | 0 | 0 |
| column | 29 | 38 | 29 | 0 | 9 |
| company-005930 | 36 | 36 | 36 | 0 | 0 |
| company-033780 | 34 | 34 | 34 | 0 | 0 |
| home | 8 | 8 | 8 | 0 | 0 |
| isa-irp | 152 | 152 | 152 | 0 | 0 |
| me-kim | 81 | 81 | 81 | 0 | 0 |
| privacy | 59 | 59 | 59 | 0 | 0 |
| terms | 46 | 46 | 46 | 0 | 0 |
| wealth | 15 | 15 | 15 | 0 | 0 |

- **칼럼 목록의 'Streamlit에만' 9개**: 값이 다른 숫자가 아니라, 글 번호·카드 제목이 화면 카드와 (눌리게 하려고 겹쳐 둔) 투명 단추에 한 번 더 적혀 같은 숫자가 두 번 세어진 것이에요. 웹 쪽 '읽은 글 수'는 웹 브라우저의 읽음 기록을 잠시 비운 상태로 견줬어요.
- **데이터 이야기**: 11장 1,418개 숫자가 모두 같아요(SVG 그림 안의 숫자 포함). 분신 대조에서도 장마다 문장까지 같았고, 다른 것은 3장 연도 단추 이름 모양('2019' / '37%' 두 줄 → '2019 · 37%' 한 줄) 하나예요. 6장 조건을 '무상증자'로 바꿔도 같은 값이 나왔어요.
- **내 정보**: 시연용 고객 kim으로 로그인해 견줬어요(81개 같음).
- **내 배당 점검(챗봇)**: 대화라 글 뽑기 대신 같은 입력을 넣어 견줬어요. `chat/script`·`chat/parse` 4건·`checkup` 3건이 웹 API와 같고(위 ①의 `checkup(예시)` 포함), 시연용 고객 kim·go의 `?auto=1` 대화를 [맞아요]까지 돌린 결과 첫 줄·세액 차이가 `/api/personas/{id}` 값과 같았어요(kim 817,700원 감소). 브라우저에서 '삼성전자 100주 → … → 맞아요' 결과와 근거 서랍·조문 찾기도 돌려 봤어요.
- 회사 보기는 예시 칩 두 곳(005930, 033780)으로 화면을, ①에서 8곳의 API 값을 견줬어요. 세무상담 신청·마이페이지는 숫자가 아니라 모형 예약 흐름이라 화면을 눈으로 확인했어요.

## Streamlit 한계로 웹과 다른 점

| 화면 | 웹 | Streamlit |
|---|---|---|
| 공통 | 로그인한 고객·칼럼 읽음·상담 신청 내역을 브라우저(localStorage)에 기억 | 이 Streamlit 세션에만 기억. 주소를 새로 열면 풀려요 |
| 공통 | 위쪽 큰 검색창에 글자를 치는 동안 후보 | 회사 목록 선택 상자(이름·코드로 찾기). 우선주는 웹 검색처럼 빼요 |
| 공통 | 링크로 화면 이동 | 단추·`page_link`로 이동(같은 세션 유지). `/analysis#ch5` 같은 장 위치까지는 못 따라가요 |
| 회사 보기 | [주소 복사] 단추, 게이지 차오르는 움직임 | 주소를 펼쳐 보여 주는 칸(복사 단추 있음), 게이지는 바로 채움 |
| 데이터 이야기 | 그림 위에 마우스를 올리면 그림 아래 글이 바뀜 | 브라우저 말풍선(SVG title)으로 보여 줌 |
| 데이터 이야기 3장 | 연도 단추·재생/멈춤 | 연도 고르기 + ▶ 재생(1.2초마다 다음 해, 재생 중 멈춤 단추 없음) |
| 데이터 이야기 6·8장 | 고를 수 없는 조건은 흐리게 | 목록에서 빼고 보여 줌 |
| 데이터 이야기 | 지금 읽는 장 목차 강조 | 앵커 이동만 |
| 점검 챗봇 | 칩·'내 답' 칸, 조회 대상 기업 이름 카드 격자, 사진은 파일 창 바로 열기, `auto=1`은 0.7초 간격 | Streamlit 단추('내 답 · ' 붙임), 검색되는 선택 상자, 단추를 누르면 업로드 칸, `auto=1`은 한 번에 넣음. 빈 글 '보내기' 흐림·새 칸 반짝임 없음 |
| 칼럼 | 용어를 누르면 풀이, 85% 읽으면 읽음, 읽기 진행 막대 | 마우스를 올리거나 포커스하면 풀이, [다음 글]을 누를 때 읽음, 진행 막대 없음. 퀴즈·묶음 탭 색칠 방식이 조금 달라요 |
| 약관 | [인쇄하기] 단추 | 브라우저 인쇄(⌘/Ctrl+P) |
| 마이페이지 | 취소 확인 창 | 작은 펼침 창에서 [취소할게요] |

## 다시 대조하는 법

```bash
.venv/bin/python app/verify/api_same.py            # ① 8000 서버가 켜져 있어야 해요
.venv/bin/python app/verify/page_numbers.py serve --dir /tmp/onepick_pages   # ② 받기 서버
# 두 화면을 브라우저로 열고 콘솔에서 글 보내기(파일 맨 위 설명 참고) 뒤
.venv/bin/python app/verify/page_numbers.py compare --dir /tmp/onepick_pages
```
