## 1. 요건 판정 — `source/core/judgement.py` (PRD F-01)

**기호:** B = 배당소득 / D = 현금 이익배당금액 총액 / NI = 법정 기준 당기순이익.

### 최종 판정

| 배당성향 | 증가 조건 | 핵심 수치 요건 |
| --- | --- | --- |
| 40% 이상 확정 | 어느 상태든 | **충족 — 가목** |
| 25% 이상 40% 미만 | 충족 | **충족 — 나목** |
| 25% 이상 40% 미만 | 미충족 | **미충족** |
| 25% 이상 40% 미만 | 보류 | **보류** |
| 25% 미만 확정 | 어느 상태든 | **미충족** |
| 배당성향 보류 | 어느 상태든 | **보류** |

| 전체 검토 상태 | 결론 |
| --- | --- |
| 필수 실체 요건 중 확정 미충족 있음 | 미충족 |
| 필요한 실체 요건 모두 충족 | 충족. 공시 이행 확인 결과 별도 기록 |
| 필요한 요건·공시 지연 등의 법적 효과 미확정 | 전체 결론 확정 보류 |

보류는 미충족과 구분한다. 가목이 확정 충족이면 증가 조건 보류와 관계없이 핵심 수치 요건은 충족할 수 있다. 주주별 특례 적용은 기업 판정 외 대상 소득·거주자·신청 요건 등을 별도로 검토한다.
