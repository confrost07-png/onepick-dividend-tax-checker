## KRX 주가

- 지금 쓰는 파일: `data/raw/krx/prices.csv` (2026-10-23 받은 `~/Downloads/prices (1).csv` 사본). `04_KRX_시세_수집.ipynb`로 pykrx로 받은 한국거래소(KRX) **일별 수정 종가**
- 적재: `raw.krx_price_daily` 1,241,639행 = 638사 × 2,157거래일(2018-01-02 ~ 2026-10-20) 중 값이 있는 칸. 상장 전·거래정지일은 행이 없음
- 시장지수: `data/raw/krx/market.csv` (원래 폴더 `data/raw/KRX/market.csv` 사본) → `raw.krx_market_index` 4,314행 = KOSPI·KOSDAQ 각 2,157거래일. 주가 거래일과 날짜가 모두 맞음
- 빈칸 사유: `data/raw/krx/일별상태.csv` → `raw.krx_day_status` 134,527행(상장 전 131,322 · 거래정지 3,130 · 마지막 거래 이후 75). 주가 빈칸 수와 정확히 같음. 종목코드는 `대상목록.csv`로 corp_code에 연결
- 알려진 문제 (원본은 고치지 않고 아래 '사용 등급'으로 표시):
  - **에스엔시스(`01294110`, `0008Z0`) 주가 미수집**: 노트북 `normalize_ticker`가 숫자 아닌 글자를 지워 `0008Z0` → `000080`(하이트진로)으로 바꿈. 노트북을 고친 뒤 이 1곳만 다시 받으면 됨. 같은 이유로 `report.csv`·`기준지수.csv`에 "하이트진로 = KOSDAQ" 줄이 잘못 들어 있음(아직 DB에 넣지 않음)

  - 거래정지 표시 없이 같은 가격이 5거래일 이상 이어지는 구간 397개(129곳, 4,038일). 최장 MH머트리얼즈 240일
  - 2026년 지수 급등락: KOSPI ±8% 초과 10일(최대 2026-07-31 +17.9%), KOSDAQ 5일, 최고 9,114.55(2026-06-22). 다른 출처와 대조 안 함
  - 마지막 날(2026-10-20)에 거래정지 중: 케이씨티(마지막 가격 10-19), 엑셈·인지디스플레(10-07)
  - 에코마케팅(`01029394`)은 2026-06-15 주식교환으로 상장폐지, 가격만 있고 회사 표(638사, 확정)에는 없음

## 교체 방법

1. 보완판 파일을 이 프로젝트의 `data/raw/`에 둡니다(`.gitignore`로 git에서 제외됨). 파일 이름이 바뀌면 `source/core/raw_tables.py`의 `FILES`도 고칩니다.
2. 다시 적재합니다. 두 스크립트는 표를 비우고 새로 채웁니다.
   ```bash
   .venv/bin/python -m scripts.load_raw --source data/raw
   ```
   ```bash
   .venv/bin/python -m scripts.build_core --source data/raw
   ```
3. 위 표의 값을 다시 세어 이 문서와 `report/검증/조문_코드_대응표.md` 9절의 '적재 결과 확인' 표를 고칩니다.
4. 교체를 마치면 이 문서 맨 위 안내를 "교체 완료(날짜, 판)"로 바꿉니다.
